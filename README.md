# EduGenie.AI - AI Learning Assistant

EduGenie.AI is a web application designed to assist students with QnA, text summarization, quiz generation, and personalized learning paths using FastAPI and Google Gemini API.

## Features
- **Ask EduGenie:** QnA support using Gemini model.
- **Summarizer:** Concise bullet-point summaries.
- **Quiz Generator:** Automatic multiple-choice questions.
- **Learning Recommendations:** Structured roadmap for topics.
